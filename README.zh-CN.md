## 为什么它不一样

市面上大多数「AI 股票 agent」生成一段像模像样的话，然后就忘了。这个更像一个**有简历的分析师**：

- **先预测，再被打分**：每天的观点白纸黑字写下、锁进台账，次日用真实价格判分——**不是模型自己给自己打分**。
- **判分是确定性的**：支撑/压力位对照真实高低点；方向用**波动率噪音带**衡量——只是随机晃动的走势记为「未定」，不算命中。
- **历史不可回改**：预测存在**只追加、哈希链**台账里，改一个字符 `verify_ledger_integrity` 就会失败。
- **它知道自己哪里弱**：战绩按**能力维度 × 市场体制 × 视野 × 置信度**分桶；月度**自省**用算出来的错误结构追问「我为什么老错」。

> 代码可以被复制，**这份复利、防篡改的历史战绩不能。**

完整方法论见 **[预测核验方法论.md](预测核验方法论.md)**（或 [English](METHODOLOGY.md)）。

## 工作流

```
研究员 → 核查员 → 复盘校验员 → 分析师 → 模拟交易员 → 撰稿人 → 交付
 收集情报   独立复核/防幻觉  检索往期+确定性核验  量价/轮动/结构  10万美元模拟盘  撰写+配图  存档+发信
      │
      └── 每条预测 ──► prediction_ledger.jsonl（哈希链）──► 次日自动判分
                                                      └──► Live Track Record
```

| 阶段 | Agent | 职责 |
|---|---|---|
| 1 | **研究员** | 采集指数、11 大 SPDR 行业 ETF、市场内部结构（七巨头/风格/VIX）、宏观外围、消息面 |
| 2 | **事实核查员** | 重新取数逐项交叉验证，标记幻觉 |
| 3 | **复盘校验员** | 检索往期预测、**确定性判分**、补充归因 |
| 4 | **盘面分析师** | 量价、轮动、内部结构、支撑压力、情景与概率 |
| 5 | **模拟交易员** | 跑 **10 万美元模拟盘**（美股个股/ETF），收盘价成交，记录流水与净资产曲线 |
| 6 | **专业投资顾问** | 渲染报告（含 K 线图）、归档、发邮件 |

板块表、K 线图、判分都由代码确定性产出，LLM 只做组织与解读。

## 📝 模拟交易（$100,000 模拟盘）

分析完成后，**模拟交易员**用一个 **10 万美元模拟账户**交易美股个股/ETF（如 `SPY` / `QQQ` / `SMH` /
`XLK` / `AAPL` / `NVDA`），按**收盘价**成交，并遵守纪律（持仓 2–4 只、单票 ≤30%、总仓位 ≤80%、约 8% 止损）。
输出完整的**交易流水**、**持仓表**、**账户汇总**与**逐日净资产曲线**。状态保存在 `paper/`（git 忽略）。

## 🪙 加密模块（BTC / ETH）

同一套「一切可核验」的流水线也能跑加密——但分析的是真正驱动它的东西：**永续合约衍生品**，而非行业轮动。

```bash
python crypto_main.py                 # 复盘最近一个已收盘的 UTC 日
python crypto_main.py --date 2026-10-09
```

- **衍生品与杠杆（核心）**：资金费率（每期 + 年化）、未平仓 OI 及变化、多空账户比/吃单比、
  近 24h 多空爆仓、期货基差。
- **ETF 资金面**：美国现货 BTC/ETH ETF（IBIT/FBTC/ETHA/FETH …）价格、涨跌、成交额与合计；
  净申赎流量结合消息面交叉判断。
- **市场结构**：总市值、BTC/ETH 主导率、**ETH/BTC 汇率**（轮动标尺）。
- **情绪**：恐慌与贪婪指数。**价格**：现货日 K（UTC）、MA20/50/200、实现波动率。
- **可执行点位**：报告末给出**多空点位表**（入场 / 止损 / 止盈 / 仓位 / 触发条件 / 证伪信号），
  其中可证伪点位写成机器可解析格式，下一 UTC 日自动判分。

加密预测写入**独立**的哈希链台账（`crypto_ledger.jsonl`），并用 Gate.io 日收盘价确定性判分——
同一套方法论，独立的加密战绩。

数据源全部免费、无需 Key：Gate.io（现货+永续）、Binance 公共数据镜像、CoinLore（全球/主导率）、
Alternative.me（恐贪）、必应搜索。详见 **[docs/CRYPTO.md](docs/CRYPTO.md)**。

> 加密 7×24 且高杠杆——本模块特别强调**杠杆拥挤度**（资金费率 / OI / 爆仓），
> 因为这正是暴涨暴跌的燃料。

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env          # 填 DEEPSEEK_API_KEY（可选：SMTP）
python main.py                # 复盘最近一个美股交易日
python main.py --self-review  # 月度自省（“我为什么错了？”）
python scripts/build_track_record.py   # 刷新 Live Track Record
```

> 美股 16:00（美东）收盘 ≈ 北京时间次日 04:00/05:00。建议收盘后运行；默认复盘日期为**美东最近交易日**。
