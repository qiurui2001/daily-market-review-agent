# 🪙 加密复盘模块（BTC / ETH）

> 本模块复用美股的「研究 → 核验 → 预测 → 验证」流水线与护城河，但面向加密 7×24 市场，
> 核心信息源是**永续合约衍生品**。数据仅供研究参考，**不构成投资建议**。

## 为什么加密要单独做一套指标？

加密与美股的最大差异：

1. **7×24 交易**，以 **UTC 00:00** 收日线；没有开盘/收盘，没有涨跌停。
2. **永续合约是流动性中心**——现货只是一小部分。真正驱动暴漲暴跌的是**杠杆拥挤度**：
   资金费率、未平仓合约(OI)、多空比、强平/爆仓。
3. **资金在主流币与山寨间轮动**，用 **主导率** 与 **ETH/BTC 汇率** 衡量，而非行业轮动。
4. 情绪极端化明显，**恐慌与贪婪指数**是有效的高频情绪代理。

## 用法

```bash
python crypto_main.py                 # 复盘最近一个已收盘的 UTC 日
python crypto_main.py --date 2026-10-09
python crypto_main.py --to you@qq.com --quiet
```

- 报告 → `reports/加密复盘_{UTC日期}.md`
- K 线图 → `reports/crypto_charts/{BTC,ETH}_{日期}.png`
- 预测台账 → `crypto_ledger.jsonl`（只追加、哈希链，**纳入版本控制**）
- 战绩页 → 运行 `python scripts/build_crypto_track_record.py` 生成 `CRYPTO_TRACK_RECORD.md`

## 分析框架（六节）

| 节 | 内容 | 关键指标 |
|---|---|---|
| 一、行情总览 | BTC/ETH 价、量、阶段涨跌；全球市值、主导率、恐贪 | 收盘、7d/30d、BTC/ETH 主导率 |
| 二、往期预测验证 | 确定性判分 + 归因 | 滚动命中率、Wilson 区间 |
| 三、衍生品与杠杆 | 杠杆拥挤度与挤兑风险 | 资金费率(年化)、OI 及变化、多空比、爆仓、基差 |
| 四、市场结构 | 资金在 BTC/ETH 间轮动 | 主导率、ETH/BTC 汇率 |
| 五、ETF 资金面 | 现货 ETF 资金参与度 | ETF 涨跌、成交额、净流入/流出 |
| 六、情绪与消息 | 情绪极端度与事件 | 恐贪指数、监管/宏观 |
| 七、多空点位与策略 | 分情景预判与可执行点位 | 支撑/压力位、**多空入场/止损/止盈/仓位**、证伪条件 |

## 衍生品指标怎么读（速查）

- **资金费率 (Funding)**：永续合约多空之间的周期性支付。**正**＝多头付钱给空头（多头拥挤）；
  **负**＝空头付钱给多头（空头拥挤）。**年化极端**（如 >30% 或 <-10%）通常预示反向挤压风险。
- **未平仓合约 (OI)**：市场上未平仓的合约总量。**价涨 OI 增**＝新多进场、趋势健康；
  **价涨 OI 减**＝空头回补/平仓、涨势存疑；**价跌 OI 增**＝新空进场。
- **多空比 (Long/Short)**：账户多空比偏高＝散户偏多、易被反向清洗。
- **爆仓/强平 (Liquidation)**：短时大量多头爆仓＝下跌加速器（瀑布）；大量空头爆仓＝轧空。
- **基差 (Basis)**：期货标记价相对现货的升贴水。持续升水＝杠杆多头火热；贴水＝观望/偏空。
- **ETH/BTC 汇率**：上升＝资金向以太坊/山寨扩散（进攻）；下降＝资金回流比特币（防御）。

## 多空点位怎么给

报告第七节给出**可执行的多空点位表**（币种 / 方向 / 入场区间 / 止损 / 止盈目标 / 仓位 / 触发条件 / 证伪信号），
并把其中可证伪的点位写成**机器可解析格式**（如「BTC 回踩 80000 支撑做多，止损 78500，目标 86000」
「ETH 反弹 2600 压力做空，止损 2700，目标 2400」），系统会在下一 UTC 日用真实行情自动核验。
加密波动大、杠杆高，点位务必配合**严格止损**，仓位宜轻。

> **不可达**，故只能提供**成交额代理**，净流入/流出须结合消息面（新闻）交叉判断。

## 确定性判分口径

与美股**完全一致**（复用 `ledger.py` 内核）：

- **压力/目标位**：窗口内最高价是否触及；**支撑位**：最低价是否触及；
- **突破/跌破位**：窗口内收盘价是否突破/跌破；**关键位**：区间是否穿过；
- **方向**：区间涨跌是否超过**波动率噪音带**（`PRED_VOL_MULT × 日波动 × √N`），带内记为「未定」不计分。

窗口按 **UTC 日**切分，行情取 Gate.io 现货日 K。评分规则变更**只对未来生效**，不回改历史。
